# Platform support

Linux is the primary development target. Build and test results apply only to the platform and compiler actually exercised. Windows, macOS, Android/Termux, binary installers and other distributions need separate validation. Several process and CLI paths are POSIX-only.

See [CURRENT_STATUS.md](CURRENT_STATUS.md) and [docs/CROSS_PLATFORM_BUILD.md](docs/CROSS_PLATFORM_BUILD.md) for dependencies and current limits.
